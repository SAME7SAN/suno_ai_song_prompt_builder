# suno_ai_song_prompt_builder
A simple program for creating song prompts for Suno AI. You can select song sections and elements with a single mouse click, including intros, instrumental passages, emotional tones, outros, and much more. We are currently at version 1.0, and we plan to introduce further enhancements in future updates. I hope you find it enjoyable, helpful, and a great time-saver. The content can be edited directly within the interface, and once finished, you can either export the generated prompt to a text file or copy it directly to paste into Suno AI.
